# Security and safety reports

1Cleaner moves files to the Trash, so the most serious bug is one that offers or removes something it shouldn't:
a file outside the expected place, data an app still needs, a symbolic link followed, or a wrong safety label.

Please report these privately to **support@onebuckapps.com** with the macOS version, the 1Cleaner version, the
category and the path (or a description if the path is private). You'll get an answer, and the fix ships in the
next release.

For anything else, open a GitHub issue.
