# Roadmap

Ideas under consideration, not promises. Open an issue to discuss one.

- Similar photos.
- Old developer toolchains: nvm/fnm Node versions, pyenv, rbenv, rustup toolchains, old JetBrains and Android
  Studio cache, log and config folders from previous versions.
- Homebrew: old versions and the download cache, removed by `brew cleanup` itself.
- Time Machine local snapshots as their own section (`tmutil`; removal may ask for an administrator password).
- Login Items and Launch Agents, including agents of removed apps.
- Files not opened for a year.

Not planned: a menu bar widget for now; malware scans, "RAM boost", removing language files from
apps, a file shredder, cleaning cloud storage.
